# Voicer

Telegram-юзербот (Telethon) для розшифровки голосових, кружечків і відео:
Groq Whisper → пунктуація/емодзі через Groq LLM → (опційно) переклад.
Керування — через веб-панель.

## Команди в чаті

- `.р` (реплай на голосове/кружечок/відео) — розшифрувати
- `.п` (реплай на текст) — перекласти
- `+chat` / `-chat` — додати/прибрати поточний чат з автотранскрипції
- `/panel` — посилання на панель керування

## Веб-панель

- `/` — `OK` (для UptimeRobot / health-check)
- `/app` — панель: налаштування, авточати, статус, перезапуск

## Змінні оточення

| Змінна | Обов'язкова | Призначення |
|---|---|---|
| `API_ID`, `API_HASH`, `SESSION_STRING` | так | Telethon-акаунт |
| `GROQ_API_KEY` | так | Whisper + LLM |
| `PORT` | ні | порт (типово 7860) |
| `PANEL_TOKEN` | ні | захист панелі; запит `?token=…` |
| `PANEL_URL` | ні | публічна база сервісу для `/panel`; на Render береться `RENDER_EXTERNAL_URL` |
| `PANEL_OWNER_ID` | ні | зафіксувати власника налаштувань (мусить дорівнювати ID акаунта бота!) |
| `UPSTASH_REDIS_REST_URL` | ні* | durable-сховище налаштувань |
| `UPSTASH_REDIS_REST_TOKEN` | ні* | те саме |
| `SELF_PING` | ні | `0` — вимкнути self-ping |
| `SELF_PING_INTERVAL` | ні | інтервал self-ping у секундах (типово 600, мінімум 60) |

\* Без Upstash на Render налаштування живуть лише до рестарту/деплою:
файлова система там ефемерна.

## Render Free: чому бот «засинає»

Render гасить Free-інстанс після ~15 хв **без вхідних HTTP-запитів**
(наявність TCP-з'єднання Telethon не враховується). Тому:

- сервіс сам пінгує власний публічний URL (`RENDER_EXTERNAL_URL` + `/`)
  кожні 10 хв — це вхідний трафік через проксі Render, інстанс не засинає;
- у панелі є картка **Keep-alive** зі станом останнього пінгу;
- UptimeRobot не обов'язковий, але корисний як зовнішній дублер (інтервал 5 хв
  на `/`);
- безкоштовний план дає 750 інстанс-годин/місяць — цілодобова робота одного
  сервісу вкладається в цей ліміт.

## Upstash (безкоштовно)

1. https://console.upstash.com → **Redis** → *Create Database* (Free, регіон ближче до Render).
2. Скопіювати **UPSTASH_REDIS_REST_URL** і **UPSTASH_REDIS_REST_TOKEN**.
3. Додати їх у Render → *Environment*.
4. Перезапустити сервіс. У панелі картка «Сховище» має показати ☁️ Upstash.

Ключ: `voicer:settings`.

Перевірка: кнопка **«Перевірити сховище»** в панелі записує поточні
налаштування в хмару, читає назад і порівнює. У відповіді видно ключ,
список owner ID у хмарі та кількість чатів.

Якщо хмара недоступна, зміни лишаються в пам'яті (`pending`) і
вивантажуються повторно (панель опитує статус кожні 10 с).

> **Важливо:** якщо задати `PANEL_OWNER_ID`, він мусить дорівнювати ID
> акаунта бота. Інакше панель і бот писатимуть налаштування під різними
> ключами. Панель показує обидва ID і попереджає про розбіжність.

## Локальний запуск

```bash
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python app.py
```
